P5 C state -> glyph/style enumeration
===================================

Scope: every production ui/app rendering branch, including unchanged A/B state
logic that composes with C. Source inventory: state-branches.txt (Go AST),
style-constructions.txt (all Lip Gloss constructors/colour setters). Contract:
design/tokens.json and docs/design/interface-design.md. I=Ink, M=InkMuted,
S=Surface, R=SurfaceRaised, A=Accent. State roles use their exact generated name.
All combinations use generated adaptive roles, not local RGB/ANSI literals.

LIVENESS AND OPERATIONS
L01 Tree/search Running and unset: blank status cell. No animated indicator.
L02 Ready=●/Ready; Lost=◌/Lost; Dead=○/Dead; Archived=▧/Archived;
    LimitReached=◆/LimitReached. State glyphs keep reserved foregrounds.
L03 Creating/restoring/killing/archiving mask every liveness glyph with blank.
    Killing/archiving retain [deleting]; [lost], [limit]/reset, [remote], model
    change and recreate context qualifiers retain explicit text.
L04 Selected tree/search status cells retain state foreground on R. Selected
    names and gaps I/R, cursor A/R. Search branch M ordinarily, I/R selected.
L05 Unselected tree names I, including archived/deleting. Branch/time M;
    suggested, not-yet-entered title M. No session name takes a liveness colour.
L06 Collapsed, unselected sessions have one row. Selected/expanded groups retain
    branch and idle detail; an empty branch never emits the bare branch glyph.
    Incomplete archive and exhausted restore remain visible without selection;
    failed-operation detail Dead, retained recovery path stays available.
L07 PTY unavailable/not-started/dead/lost/missing-tab fallback: plain explanation
    in I. Runtime operation handlers do not introduce another state palette.
